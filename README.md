# Chl-a Field Forecasting for Data-Scarce Small Inland Waters

Code, data, and trained models for the paper *Chlorophyll-a Field Forecasting for Data-Scarce Small Inland Waters by Multi-Water Pretraining and Few-Shot Transfer on Sentinel-2 Image Time Series* (submitted to the International Journal of Applied Earth Observation and Geoinformation).

This repository is being prepared. The following will be released here:

- Source code for corpus construction, pretraining, few-shot transfer, and evaluation
- The multi-water pretraining corpus (441 waters) and the transfer-learning corpus (five evaluation waters)
- Pretrained and transferred model weights

A citation entry will be added once the paper is published.
